## 一、三分钟上手

1. **双击 `index.html`**（或访问部署地址）打开游戏；
2. 开局选择**难度剧本**（顺遂 / 普通 / 艰难 / 天选），写下姓名与出生信息；
3. 点击顶栏的**开始 / 继续**让时间流动，或使用**单步**一次推进一个月；
4. 时间流动中会出现两类交互：
   - **抉择弹窗**：人生岔路，停下来让你选（此时时间冻结，不消耗人生）；
   - **行动栏**：你主动做的事（读书、锻炼、加班、旅行……），按月冷却，随点随生效；
   - **习惯栏**：🌱 立下一个长期习惯，每月坚持累积，坚持到底会"内化"成性格的一部分；
5. 主角死亡后进入**结算页**：一生评分、五维雷达图、结局定性、时间线、生命曲线、成就墙。

一句话策略：**抉择决定人生的方向，行动决定人生的厚度**——两者都会累积到故事积分里。

## 三、时间与速度

- 时钟从 **1990 年**前后开始，按**真实公历**推进（含闰年），显示年龄、年月与季节；
- 支持 **暂停 / 继续 / 单步 / 多档速度**；
- **抉择弹窗出现时时间冻结**：无论你想多久，人生都不会被"等掉"；
- 主角死亡后时间停止，自动进入结算。

## 四、核心数值

| 数值 | 含义 | 过低 | 过高 |
|------|------|------|------|
| 生命 | 身体健康度 | 死亡风险显著上升（寿命系统按 Gompertz 曲线放大风险） | — |
| 免疫 | 抵抗力 | 更易感染、更易转慢性 | — |
| 心情 | 情绪基调 | 触发心理事件、影响社交与抉择 | — |
| 智力 | 认知能力 | 影响升学与部分职业 | — |
| 知识 | 学识积累 | 影响高考/科研类结果 | — |
| 财富 | 现金与净资产（单位：万元） | 负债会持续打击心情与免疫 | 存款计息存在上限 |

三者关系：**疾病**扣生命与免疫、**心理**侵蚀心情与免疫、**财务**影响心情、
**行动**是玩家唯一能主动调节它们的手段。

## 五、行动机制

行动栏是"两次抉择之间你能主动做的事"，**按月冷却、点击即生效**，效果统一走
`applyEffects` 通道（与抉择同一套数值规则）。

> **v1.7.0 行动抉择化（G8）**：旅行 / 兼职 / 捐助三个行动升级为**弹窗式选择**——
> 点击后不直接生效，而是弹出 4~5 个选项让你挑（如旅行可选「海边 / 高原 / 出国 / 短途 / 算了」），
> 各选项效果、花费、风险各不相同，部分选项有门槛（如出国需财富 ≥ 32）。
> 冷却与熟练度在点击时就扣减，选完后效果落地。

买入 A 股 / 清仓 A 股 / 买入虚拟币 / 清仓虚拟币，冷却均为 1 个月，
需先完成"入市"（详见第八章）。

### 5.4 两套隐藏机制

- **性格漂移（可塑）**：行动会缓缓塑造大五人格（如锻炼提升 C、冥想降低 N），
  速率以"年/月"计，远慢于体征，且**每年向出生本性回弹**、总偏移封顶 ±15；
- **伏笔埋设**：部分行动会埋下伏笔种子（如锻炼埋"健身"、捐助埋"善意"），
  若干月后触发回响，并被后续剧情回收，形成因果链。

## 六、抉择机制

抉择是**被动的人生岔路**，由系统按月节奏 + 里程碑 + 随机岔路抽取，命中时：

1. 主循环**冻结**，弹窗给出 2–3 个选项；
2. 选项可能带**风险徽章**（骰点判定，成功/失败各有不同结果）、**条件门槛**（年龄/学历/财富/
   职业/前置伏笔）与**剧情提示**；
3. 你的选择立即结算（体征、财产、标记、伏笔、故事线），随后时间恢复流动。

当前共有 **146 个抉择事件**，覆盖五类：

| 类别 | 说明 |
|------|------|
| 生活流 | 恋爱、相亲、买房、生育、赡养、健康起居等日常岔路 |
| 时代 | 下海、入世、非典、奥运、智能机、股灾、房价、疫情、AI 等按年份窗口触发 |
| 投资链 | 入市、牛市狂热、黑天鹅暴跌、币圈时代等连锁事件 |
| 收官 | 退休、遗产规划、养老方式、临终关怀、大寿庆典（60 岁后成组出现） |
| 随机岔路 | 低概率的突发境遇（意外、机遇、闲事） |

**因果门控**：部分抉择只有在"曾经埋下某个伏笔"时才出现（`requiresSeed`），
选择后消耗该伏笔（`consumesSeed`），并可能埋下新的伏笔或登记延时回响（`delayed`）。
这是"十年前的一个决定，今天找上门"的机制来源。

## 七、资产机制（房产 / 车辆 / 房贷）

### 7.1 房产

| 档位 | 价格 |
|------|-----:|
| 单身公寓 | 60 万 |
| 两居室 | 140 万 |
| 三居室 | 260 万 |
| 别墅 | 600 万 |

- 名下**最多 3 套**；
- 可**全款**或**按揭**：按揭首付 **30%**、贷款年限 **25 年**、年利率 **4.9%**；
- **银行审核**：月供不得超过月收入的 **60%**，否则无法获批；
- 持有成本：每年维护费为**原值的 1.2%**；
- 房价随**资产价格指数**演化：年均增长 1.2%，叠加随机漂移（±1.8%）与剧本影响；
- 卖出按成交价收取 **2%** 税费。

### 7.2 车辆

| 档位 | 价格 |
|------|-----:|
| 代步车 | 12 万 |
| 中级车 | 30 万 |
| 豪车 | 90 万 |

- 名下**最多 2 辆**；
- 按揭首付 **20%**、贷款年限 **5 年**；
- 每年固定养护/油费/保险 **0.6 万**，且车辆每年**折旧 12%**（占现价）；
- 卖出同样收取 **2%** 税费。

### 7.3 现金与净资产

- 现金存款按年计息，利率 **1.5%**，**计息上限 200 万**（超出部分不计息）；
- 净资产达 **300 万**会点亮"广厦千间"相关成就标记；
- **房贷未还清时计入负债**，负债会持续压制心情与免疫——量力而行。

## 八、投资机制（A 股 / 虚拟币）

- **解锁**：18 岁后触发"朋友拉你开户入市"抉择，**开户三选一**（v1.8.0）：
  📈 只开A股 / 🪙 直奔虚拟币 / 🏦 双开——行动栏只会出现**已开户市场**的买卖按钮；
  - 后来想补开另一边：币圈时代事件（2013 比特币元年 / 2017 币圈疯狂）参与即自动开币户；
    平时也有「🪙 币圈开户诱惑」「📈 证券公司来电」两条补开户事件轮流入池；
- **买入**：每次动用"可投现金"的 **25%**，单笔最低 **3 万**；卖出按**现价**结算真实盈亏；
- **情绪反馈**：卖出盈利心情 +6，亏损心情 -8；
- 行情**逐年随机游走**，并可能发生崩盘：

| 标的 | 起始价 | 年漂移 | 年波动 | 年崩盘概率 | 崩盘跌幅 |
|------|-------:|-------:|-------:|-----------:|---------:|
| A 股 | 100 | +6% | 20% | 7% | -35% |
| 虚拟币 | 20 | +14% | 60% | 16% | -62% |

虚拟币是"高波动高赔率"的选择：长期期望更高，但崩盘概率与跌幅也远大于 A 股。
行情状态随存档保存，读档后继续演化。

## 九、故事线与故事积分

### 9.1 五维故事积分

你的每一次抉择与行动都会按关键词归入五个维度（起点 8，范围 0–100）：

| 维度 | 累积来源（关键词示例） |
|------|------------------------|
| 雄心 | 创业、升职、跳槽、加班、事业、置业、购房、副业 |
| 善心 | 捐助、志愿、陪伴、赡养、照顾、探望、亲情 |
| 冒险 | 风险、投资、股票、虚拟币、杠杆、抄底、投机 |
| 智识 | 学习、读书、考试、研究、进修、培训、学术 |
| 活力 | 锻炼、健身、运动、旅行、体检、养生、活力 |

- 抉择命中关键词 **+4**，行动命中 **+3**；
- 结算页绘制**五维雷达图**，并与你出生时的大五人格 OCEAN 对照——
  "先天气质 vs 后天轨迹"的差异一目了然。

### 9.2 六条故事线

伏笔种子按主题归入故事线，记录"开了哪些线、推进到哪"：

| 故事线 | 代表种子 | 主题 |
|--------|----------|------|
| 事业 | 老板、新工作、倦怠 | 职场起伏与身份跃迁 |
| 财富 | 投资人、负债习惯 | 财富积累与风险敞口 |
| 情感 | 冷战 | 恋爱、婚姻、疏离与和解 |
| 健康 | 健身 | 身体管理与疾病抗争 |
| 家庭 | 亲情善意 | 父母、子女、赡养与遗产 |
| 心境 | 旅居向往 | 压力、低谷、迷惘与自我和解 |

- 有伏笔即视为"开线"（起步进度 20）；**埋下伏笔 +14**，**回响 / 高光节点 +6**；
- 未命中任何关键词的行为归入**心境**线——你的人生无论如何都会留下痕迹。

### 9.3 八类结局

结算时按五维与故事线状态判定结局（阈值以 `config.story` 与 `story.js` 为准），例如：

| 结局 | 参考条件 |
|------|----------|
| 赌神 | 雄心与冒险双双极高 |
| 大儒 | 善心与智识双双极高 |
| 完满人生 | 五维普遍高企 |
| 涅槃 | 经历低谷后故事线完成逆转 |
| 逍遥 | 活力 / 心境线主导 |
| 静好 | 家庭 / 情感线主导且心态平稳 |
| 虚度光阴 | 五维普遍低迷 |
| 平凡一生 | 未触发任何特殊条件时的兜底结局 |

结局会写入全局标记并广播，结算页据此展示专属文案。

## 十·五、习惯、留白与暖意

### 习惯养成闭环（v1.3.0）

行动栏是"做一次"的事，**习惯栏是"一直做"的事**——它把"性格可塑"从被动变主动：

- **立习惯**：12 岁起，在习惯面板从 8 个习惯里挑一个（坚持锻炼 / 每日阅读 / 冥想静心 /
  坚持写作 / 强制储蓄 / 经营友情 / 志愿服务 / 学做饭），点击图标即可开始；
- **坚持**：每度过一个月，连续纪录 `streak` +1，并持续获得**该习惯的小额每月增益**；
- **内化**：坚持满各自的阈值月数（10~18 个月不等），习惯**内化**——一次性获得性格漂移
  （写进你的 OCEAN）与属性增益，成为"你就是这样的人"。已内化的习惯会戴上 ✔ 徽章；
- **放弃**：随时可放弃，**只断连击、不惩罚**，也不会抹掉已经内化的习惯；
- **结算**：每内化 1 个习惯，一生评分 +10 分。

> 习惯完全活在它自己的数据里，不调用、不影响任何其它系统——你可以把它当成"给主角的一本
> 自我修炼手册"。

### 未竟之事 · 人生留白（v1.3.0）

生命尽头，结算页会温柔地列出**你这辈子从没走过的路**（最多 5 条）：

| 留白 | 判定 |
|------|------|
| 亲密与羁绊 | 从未恋爱、成家或育有子女 |
| 膝下承欢 | 一生从未养育过孩子 |
| 安家置业 | 一生从未拥有属于自己的房子 |
| 远行求学 | 从未走出国门见识更大的世界 |
| 孤注一掷 | 一生四平八稳，从未为某件事赌上过 |

这一栏**只是呈现、不做评判**——它让每一次重开都有"下次换条路走走"的念想。

### 暖事件 · 小确幸（v1.3.0）

除了疾病、意外、亏损这些挑战，人生里也有一批**正向微事件**会随心情与季节悄悄出现：
邻居送菜、旧友重逢、孩子第一次叫你、雨后初晴、流浪猫蹭你、顺手帮了陌生人……
它们多数在你**心情偏低**时更可能出现（人生会在低谷时递来一点温度），用来平衡整体情绪曲线。

### 负债催收链（v1.4.0）

当你的**财富变成负数**（房贷断供、投资爆仓、创业失败……），欠债不再是账面上一个数字——
催款会**一级一级压上来**，每一次都要你选"滚雪球"还是"止血"：

| 阶段 | 事件 | 说明 |
|------|------|------|
| ① 逾期 | 📵 逾期的提醒 | 短信从客气变警告。**还上一部分**可暂时停催；**拖延/装看不见**会埋下 `in_collection` 伏笔，并把催收往后推 1~2 个月 |
| ② 来电 | 📞 催收来电 | 电话一天七八个。**商量还款计划**能缓和；**拉黑**或**对骂**会把事情升级，导向上门 |
| ③ 上门 | 🚪 有人上门了 | 两个陌生男人站在门外。**好好谈争取分期**可签协议止损；**闭门不出**会一路拖到法院 |
| ④ 传票 | ⚖️ 法院传票 | **应诉调解**背分期但保住信用；**缺席判决**会让你成为"老赖"（打上 `bad_credit`） |

链条里还有两个**转折点**：

- **🏦 协商债务重组**：负债较深（欠款超 8 万）时，银行可能主动提出重组——
  接受可**让财富回升一截、大幅减压**，是重要的止血出口；
- **🎉 最后一笔**：当财富重新回到 0 或以上，触发"还清"收尾，补上 `debt_free` 标记，心情大幅回暖。

> **欠得越深，日子越难熬**：负债压力按**深度分级**——从"入不敷出"到"走投无路"，
> 每深一档，每年被扣的**心情、免疫、心理压力**都会加重。早还早脱身。

### 消费模式（v1.5.0）

钱攒下来只是数字，花出去才叫生活。**消费模式**把财富变成"能兑换的生活体验"，
面板在行动区下方，分三栏：

| 类别 | 玩法 | 说明 |
|------|------|------|
| 🛋️ **耐用品** | 买下 → 持有多年 → 持续加成 | 每件有价格、持有年数与残值。**持有期间每月 / 每年给属性加成**，逐年折旧；到期或回吐残值退役，也可随时折价卖出（扣 `15%` 手续费） |
| 🍲 **一次性消费** | 花钱 → 立刻兑现 | 一顿火锅、一场电影、一次 SPA、一顿米其林、一张头等舱……**即时给心情 / 免疫 / 心理减压**等效果 |
| 🧑⚕️ **服务业** | 按月订阅 → 长期加成 | 健身房、家政、营养师、私人医生、心理咨询、管家……**每月扣月费、每月给加成**，可随时退订 |

**按财富分层解锁**——现金越多，能解锁的档次越高：

| 档位 | 现金门槛 | 你能买到 |
|------|----------|----------|
| 温饱 | 0 万起 | 单车、游戏机、火锅、电影、健身房、家政 |
| 小康 | 15 万起 | 公路车、音响、相机、SPA、演唱会、营养师 |
| 富足 | 120 万起 | 钢琴、名表、按摩椅、米其林、头等舱、私人医生 |
| 奢华 | 600 万起 | 游艇、艺术品、泳池别墅、游艇派对、拍卖行竞拍、管家 |

未解锁的项**灰显并提示还差多少万**，余额不够时会抖一下。开局是"温饱"档，
所以**刚起步时能花的不多**，得先把日子过起来。

> **订阅是消耗不是负债**：服务月费从现金里直接扣，**扣不动就自动停订**（不会产生负债），
> 面板会标记已停订项等你续上。

消费会进入**评分**（"品质"分项：最高消费档 + 累计消费额，封顶 60 分），
并解锁 **8 枚消费成就**：犒劳自己、享受生活、家当齐全、付费买省心、品质生活家、
只为高兴、千金散尽、张弛有度——注意最后一枚要求你**既会花也会攒**。

其中与金手指有关的两类：

- **使用痕迹**（照常解锁，不额外惩罚）：🧬 改写规则、💰 钞能力初体验、📊 人心可读，

- **纯净向**（要求三个模块一次都没用过）：🪶 凭自己、🕯️ 素手而为、🧱 白手起家。

## 十二、存档、音效与安装

### 12.1 存档 / 读档

- 提供 **3 个本地存档槽位**（浏览器 `localStorage`），支持随时保存与读取；
- 游戏中按节奏**自动存档**，死亡时强制存档；另有独立的「自动续档」槽：关页 / 跨年 / 读档后自动写入，重开新局自动清掉；
- 重新打开游戏若检测到上次有未完成的人生，会**自动续上**（详见 13.6）；
- 读档会按 `key/id` 重建疾病配置、待处理抉择、伏笔与计时器等运行时状态；
- 换浏览器 / 清理浏览器数据会丢失存档（数据仅存于本机）。

### 12.2 音效

- 音效由 **Web Audio 合成**（不需要任何音频文件），包含生日、疾病、婚嫁、加薪、
  成就、买入、离世等提示音与轻量背景音乐；
- **默认静音**，顶栏可一键开关并调节音量；暂停或抉择冻结时背景音乐自动压低；
- 浏览器要求"首次用户交互后才能播放音频"，因此首次点击后才会有声音。

### 12.3 移动端与安装

- 响应式布局：桌面多栏 → 窄屏单列（断点 900px / 600px），横屏另有专项适配，触屏可玩；
- 通过 `http(s)://` 访问时，顶栏会出现**安装**按钮，可安装到桌面或手机主屏全屏运行；
- 以 `file://` 双击打开时，浏览器不允许注册 Service Worker，因此**离线缓存与安装功能不可用**
  （游戏会自动降级，其余功能正常）。

## 十三、金手指：三扇各走各的门

> **默认全部关闭**，想爽再自己去开。三个模块之间没有任何关系——

### 13.1 🧬 海克斯 —— 改写规则

资源：**算力 HE**（18 岁后每月回充 4 点，每解锁一枚成就 +8，也可用自己的健康 / 免疫 / 心情"氪命"兑换）。

| 外挂 | 效果 | HE | 冷却 |
|---|---|---:|---:|
| 🎲 命运重掷 | 撤回当前人生岔路并重抽一次 | 18 | 6 月 |
| 🍀 概率倾斜 | 90 天内偶然判定成功率 ×1.35 | 26 | 3 月 |
| ⏩ 时序快进 | 立刻跳过 6 个月 | 30 | 12 月 |
| ⏪ 回溯 | 回到上个月初（终身 2 次） | 90 | — |
| 🦾 义体改造 | 免疫上限 +20（每年维护费 + 心情 -1） | 120 | 终身 1 次 |
| 🛡 死亡豁免 | 下次死亡时拦下，回血到 30 | 160 | 终身 1 次 |
| 🧠 神经加速 | 指定行动熟练度直接拉满（宗师） | 50 | 2 月 |
| ♾ 无冷却 | 本月所有行动冷却清零一次 | 20 | 2 月 |

**代价**：氪命是真的掉血（5 点健康 → 14 HE，5 点免疫 → 10 HE，10 点心情 → 5 HE），
义体每年要交维护费；结算时按累计消耗 HE 折损分数（下限 0.4）。

### 13.2 💰 神壕 —— 钞能力

不额外发货币，直接用**现金 + 每月操作额度**（额度随净资产增长）：

- **提款**：按真实年份缩放的一笔钱直接入账，超出本月额度会被拒绝；
- **钞能力兑换**：🏥 私立医院贵宾套餐（80 万，健康 +12）、🏋️ 私人教练（30 万，免疫 +8 心情 +2）、
  🥂 一掷千金的饭局（40 万，心情 +10）、📚 重金请名师（25 万，知识 +15 智力 +1）；
  **同一条目本月第二次起效果递减到 0.6 倍**，大额还会带来性格漂移（省钱幻觉、更容易焦虑）；
- **一次性清债**：按剩余负债收 10% 手续费，直接把按揭结清（失败会原额退还手续费）。

**代价**：净资产越过阈值后，有概率招来延时"树大招风"——税务稽查、远房亲戚与
别有用心的朋友一起找上门；结算时按累计注入金额折损分数（下限 0.5）。

### 13.3 📊 人数数据化 —— 把人变成数据

给身边每个人挂一张**隐藏数据卡**：好感 / 现世价值 / 真诚度 / 核心标签 / 可支取人情 / 波动性。
资源是**观测点 DP**（每月回充 3 点，结交、成家、添丁各回一点）。

| 能力 | 效果 | DP |
|---|---|---:|
| 👁️ 读取面板 | 揭示某人的隐藏数值（默认雾化） | 3 |
| 🎁 拉近关系 | 好感 +（真诚度低 / 波动大的人可能适得其反） | 5 |
| 🪝 支取人情 | 消耗 10 点人情换实质收益（内推 / 借钱 / 摆平麻烦 / 内部消息） | 8 |
| ✂️ 割席 | 立刻断绝往来（心情 -6；亲情关系割不断） | 6 |
| 🖋️ 改写标签 | 扭转此人对你的核心印象（终身 2 次） | 30 |
| 🔍 全图雷达 | 2 个月内按好感排序显示所有关系人 | 12 |

**代价**：观测点与人情都要花；真诚度低的人会当面答应、转身掉链子；

### 13.4 三件事请放心

## 十四、常见问题

**Q：为什么时间不动？**
A：可能处于暂停状态，或有抉择弹窗未处理（弹窗期间时间冻结是设计如此）。

**Q：为什么行动按钮是灰的？**
A：三种原因——年龄 / 财富 / 职业等门槛未满足、处于冷却中、或该职业不匹配（行业专属行动）。

**Q：为什么买不了房？**
A：月供不得超过月收入的 60%（银行审核）；此外房产上限 3 套、车辆上限 2 辆。

**Q：为什么收入看着多，心情还是很差？**
A：检查心理卡片——高压力 / 抑郁会持续侵蚀心情，且负债同样会压制心情与免疫。

**Q：为什么读档后没有声音？**
A：音效默认关闭且需首次点击交互；请在顶栏开启音效开关。

**Q：`file://` 打开时提示无法安装 / 无法离线？**
A：属于浏览器安全策略，改用本地静态服务器或 `http(s)` 部署即可获得完整 PWA 能力。

**Q：同一局重开还会一样吗？**
A：不会。每局使用随机种子；但调试与测试可通过固定种子复现同一人生。

**Q：金手指藏在哪儿？会不会污染我认真跑的一局？**
A：顶栏行动条下方那排 🧬 💰 📊 按钮就是，**默认全关**。关着的时候模块不掷随机数、不写任何字段，
等于它不存在；只有主动打开并真的动手，才会 accrue 各自的资源与代价。

**Q：开了挂还能正常解锁成就吗？**
A：能，普通成就照常解锁、不额外扣罚；只是评分分项会各自列出对应模块的折损行，
而 🪶 凭自己、🕯️ 素手而为、🧱 白手起家 这几枚纯净徽章要求三个模块一次都没用过。

## v2.2.0 更新

### 🚀 场景模式玩法变体（开局选剧本，玩法完全不同）

开局选择器新增三档，现有顺遂/普通/艰难/天选不变：

**🚀 创业人生**——高风险高回报
- 事件率 +30%，投资波动 +50%
- 5 条专属事件链：💡有个想法 → 🌱种子轮融资 → 🔄要不要转型 → 🔥烧钱危机 → 🎉退出时刻
- 融资有风险分支（可能融到也可能被拒），烧钱危机可选裁员/抵押房子/认赔出局
- 创业的每一步都是赌博，但成功退出可以实现财务自由

**🏙️ 北漂十年**——初始极穷，真实生存压力
- 出身更差（贫穷家庭概率高），疾病率 +20%
- 4 条专属事件：🏠房租又涨了 / 🚇挤地铁 / 📞想家了 / 💰谈加薪
- 每条都是北漂的真实痛点：房租涨了只能搬更远、通勤三小时、想家但请不了假

**🛋️ 躺平模式**——慢节奏低压力
- 事件率 -30%，疾病 -20%，投资崩盘 -40%
- 4 条专属事件：☕平静的一天 / 🎨捡起爱好 / 💤做了个好梦 / 🌊想通了一件事
- 每条都是低成本的正向微事件，适合想体验"平平淡淡才是真"的玩家

> 💡 场景专属事件只在对应场景下触发，通用事件（~115 条）全场景可用。
> 也就是说每个场景实际可触发 **~120 条**事件。
